# Clínica de Psicologia (React + Vite)

Site institucional moderno e acolhedor, com animações suaves (Framer Motion), rotas (React Router) e ícones (react-icons).

## Requisitos
- Node.js 18+

## Instalação
```bash
npm install
```

## Desenvolvimento
```bash
npm run dev
```

## Build de produção
```bash
npm run build
npm run preview
```

## Estrutura
- `src/components/`: Header, Footer, ServiceCard, DoctorCard
- `src/pages/`: Home, Sobre, Doutores, Perfil do Doutor
- `src/data/doctors.js`: Base de dados simples dos profissionais
- `src/styles/global.css`: Tema, tipografia e responsividade
